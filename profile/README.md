**Independent software studio. Software that ships.**

## Products

### [Zimer](https://zimer.klectr.dev) — time tracking for invoicing

Timer to invoice in two clicks. The time tracker that does one thing, well. Self-host free forever, or use the hosted version.

`Bun` · `HTMX` · `SQLite` · [Source](https://github.com/Klectr/zimer)

### [Zlern](https://zlern.com) — homeschool planning for families

Lessons, scheduling, and progress tracking in one place — built for a real homeschool family, refined in daily use.

`React` · `TypeScript` · `Supabase` · [Source](https://github.com/Klectr/zlern)

### [Zlorb](https://github.com/ArmstrongOSS/zlorb) — hands-free deploys

A lightweight CI/CD daemon written in Rust. It watches your git repos, fast-forward pulls when they change, and runs your build — so deploying becomes something you stop thinking about.

`Rust` · `systemd` · [Source](https://github.com/ArmstrongOSS/zlorb)
